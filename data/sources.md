### https://github.com/vbalagovic/cars-dataset
Okayish dataset, contains a lot of information, good structured data about the engine. The problem is is that it doesn't exactly have the same naming conventions as do I or any other sources for that matter so it will be really hard to link it to the other data.

### https://figshare.com/articles/figure/DVM-CAR_Dataset/19586296/2?file=38754867
Same problem as with the one above, nothing special, but a lot of cars, structured info.

## https://www.autoevolution.com/search.php
Decent website, the info that is in there is the same that you can find in wikipedia, furthermore it is really well structured and easy to scrape! On the other hand, it still has some information missing and it doesn't go as much into the detail as I would like (for example: some E24 versions are missing AND there is not "facelift" or "e24/1" in there).

# https://www.automobile-catalog.com
Amazing dataset, has everything I need (except really old or rare cars but we can do without these). Could be a bit hard to extract information because the structure is not always the same, but contains INSANE amount of information, with all the makes, models, variants, and even to changes to variants through different years of production. Also contains pictures for every year, has specs for all markets. Information wise feels a bit richer than wikipedia (at least for the 15 cars that I have manually checked).

Update: This website has really strict terms of use so I will not be using it, however, I will be checking my data by comparing it to this website.

# Wikipedia
Great source of information with huge amounts of detail, however, it is usually not structured well enough to allow for easy scraping.
